# 🖐️ HandFlow

**HandFlow** は、**指のジェスチャー**に応じてパーティクルがリアルタイムに動き、反応する没入感のある Web アプリケーションです。

<img width="800" height="500" alt="HandFlowDemo" src="https://github.com/KrishBharadwaj5678/HandFlow/raw/main/HandFlowDemo.gif" />

## 🚀 主な機能

| 機能                        | 説明                             |
| ------------------------- | ------------------------------ |
| 🖐️ **ジェスチャー操作**          | 指の動きでパーティクルをリアルタイムに操作できます。     |
| 🎥 **MediaPipe トラッキング**   | 高精度なリアルタイム手検出によるスムーズな操作を実現します。 |
| 🎨 **ダイナミックなパーティクルエフェクト** | 滑らかで美しいパーティクルアニメーションを表示します。    |
| ⚡ **リアルタイムパフォーマンス**       | 高速で滑らかなインタラクションのために最適化されています。  |
| 💻 **ブラウザ対応**             | Web ブラウザ上でそのまま動作します。           |
| 🎮 **楽しくインタラクティブ**        | 手の動きを魅力的なビジュアルアートへと変換します。      |

---

## 🛠️ 技術スタック

| 技術                | 用途                         |
| ----------------- | -------------------------- |
| 🌐 **HTML**       | Web アプリケーションの構造            |
| 🎨 **CSS**        | スタイル、レイアウト、デザイン            |
| 🧠 **JavaScript** | インタラクションおよびパーティクル制御のコアロジック |
