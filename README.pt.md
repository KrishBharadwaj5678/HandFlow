<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/HandFlow/raw/main/favicon/favicon.svg" width="35"/> HandFlow</h1>

<p align="center">
  HandFlow é uma experiência web imersiva onde partículas se movem e reagem aos seus <b>gestos dos dedos</b> em tempo real.
</p>

<p align="center">
  <img width="800" height="500" alt="HandFlowDemo" src="https://github.com/KrishBharadwaj5678/HandFlow/raw/main/HandFlowDemo.gif" />
</p>

## <img src="https://github.com/KrishBharadwaj5678/HandFlow/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
| ------------------------------- | ------------------------------------------------------- |
| 🖐️ **Interação por Gestos** | Controle o movimento das partículas usando seus dedos |
| 🎥 **Rastreamento MediaPipe** | Detecção precisa das mãos em tempo real para interação |
| 🎨 **Efeitos Dinâmicos de Partículas** | Animações suaves e visualmente atraentes de partículas |
| ⚡ **Desempenho em Tempo Real** | Otimizado para interações rápidas e fluidas |
| 💻 **Baseado em Navegador** | Funciona diretamente no seu navegador web |
| 🎮 **Divertido e Interativo** | Transforme movimentos em visuais artísticos incríveis |
