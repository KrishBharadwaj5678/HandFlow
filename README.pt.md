# 🖐️ HandFlow

**HandFlow** é uma experiência web imersiva em que partículas se movem e reagem aos **gestos dos seus dedos** em tempo real.

![HandFlowDemo](https://github.com/KrishBharadwaj5678/HandFlow/raw/main/HandFlowDemo.gif)

## 🚀 Recursos

| Recurso                                | Descrição                                                           |
| -------------------------------------- | ------------------------------------------------------------------- |
| 🖐️ **Interação por Gestos**           | Controle o movimento das partículas usando os dedos.                |
| 🎥 **Rastreamento com MediaPipe**      | Detecção precisa das mãos em tempo real para interação.             |
| 🎨 **Efeitos Dinâmicos de Partículas** | Animações de partículas suaves e visualmente impressionantes.       |
| ⚡ **Desempenho em Tempo Real**         | Otimizado para interações rápidas e fluidas.                        |
| 💻 **Baseado no Navegador**            | Funciona diretamente no seu navegador web.                          |
| 🎮 **Divertido e Interativo**          | Transforme seus movimentos em incríveis efeitos visuais artísticos. |

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia        | Finalidade                                     |
| ----------------- | ---------------------------------------------- |
| 🌐 **HTML**       | Estrutura da experiência web                   |
| 🎨 **CSS**        | Estilização, layout e design visual            |
| 🧠 **JavaScript** | Lógica principal de interação e das partículas |
| ✋ **MediaPipe**   | Rastreamento das mãos em tempo real            |
